# TechRadar — 需求定稿

> 版本 v1.0 · 2026-08-18 · 经 6 视角（产品 / 架构 / 数据源 / Agent&记忆 / 排序 / 终端用户）评审后修订

## 1. 定位

一个**单用户的个人技术情报台**：

- 持续从多平台采集技术动态；
- 由 Agent 阅读、总结、打标、关联，沉淀为可检索的长期记忆；
- 每天早上以 Telegram 日报推送"今天值得看的"（≤ 一屏半，可在 Telegram 内闭环操作）；
- 能回答"那个项目叫什么来着 / X 技术最近发生了什么"；
- 收藏过、深挖过的东西有新动静时**主动提醒**；
- 按需触发"研究助手"深挖一个项目 / 论文，输出报告落库并投影到 Obsidian。

**核心价值**（区别于所有现成热榜聚合器）：个性化、长期记忆、主动提醒、每天 15 分钟内看完。

**明确不做**：多用户、社会类热榜（微博 / 抖音 / 知乎热搜）、通用新闻。

## 2. 用户与场景

用户：忙碌的后端 / AI 方向开发者，每天最多 15 分钟看技术动态，同时关注中文圈（公众号 / 掘金 / V2EX）与英文圈（X / HN / GitHub / arXiv），讨厌重复与噪音，常需回头找"之前看到的那个东西"。

一天的典型旅程：

| 时间 | 场景 | 系统行为 |
|---|---|---|
| 08:00 | 手机收到 Telegram 日报 | ≤ 8 条主条目 + 折叠区，每条带 ⭐收藏 / 🔍深挖 / 🙈少来 按钮 |
| 08:30 | 打开 Web 深读 | 单流"今日未读"，读完标 done；Inbox 看收藏 |
| 中午 | 想起某个东西 | 在 Telegram 直接发一句模糊描述 → 返回项目名 + 当时卡片 |
| 下午 | 想深挖 vLLM 0.9 | 点 🔍 → 10 分钟内收到 ≤ 500 字报告 + Obsidian 落页 |
| 周末 | 回顾 | 周报："我这周收藏了什么" + "收藏过的东西本周有新动静" |

## 3. 功能清单

### 3.1 采集层

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0 | 插件式 fetcher 基类 | 统一 RawItem 输出；内置限流、指数退避、月预算、健康记录 |
| P0 | 3 个稳定源 | HN Algolia、GitHub Search/REST、1 个 RSS（如 Hugging Face papers 或掘金前端/AI 频道） |
| P0 | 源健康监控 | source_health：last_success / consecutive_failures / 条数；连续 2 次异常 → 日报尾部告警 |
| P0 | 指标快照 | snapshots 时间序列；P0 只记录不参与排序 |
| P0 | canonical_key 硬去重 | 短链展开、去 utm、GitHub owner/repo、arXiv id、DOI；同 key 合并为一个 item 多个 item_sources |
| P0 | 订阅配置 YAML | topics（关键词、boost、sources）、authors（白名单 + 权重）、entities（白名单实体） |
| P1 | 更多稳定源 | arXiv、GitHub Releases Atom、Dev.to、Product Hunt、RSSHub 自建（掘金 / V2EX / 各博客） |
| P1 | 手动投喂 | Telegram 转发链接 `/add`，作为最强兴趣信号 |
| P1 | 全文抓取 | 正文 / README / 论文摘要，content_level 字段标记质量 |
| P1 | 中英去重 + 信息差标记 | 同一事件跨语言合并；标记"国内独有 / 海外独有 / 双边" |
| P2 | 公众号（wewe-rss，作者白名单，不参与热度）、X（twitterapi.io，List 驱动） | 待日报稳定后再接；架构 Day1 预留 |
| — | 砍：泛社会热榜、JS 渲染反爬抓取、浏览器插件 | |

### 3.2 理解层（Agent）

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0 | 统一 LLM 调用层 | 结构化输出（Pydantic schema）、prompt 缓存、usage 记账、日预算、失败落 agent_tasks 不阻塞管线 |

| P2 | 开放式实体抽取 + 别名合并 + 人工确认队列 | |
| P2 | 事件级 LLM 综合摘要 | |
| — | 砍：独立翻译步骤、LLM 0-10 绝对相关性打分 | |

### 3.3 记忆层

三类记忆：

- **条目记忆**：items + 摘要 + 标签 + embedding（P1）+ 时间 + 来源 → 检索
- **实体记忆**：entities（canonical_name / aliases / 外部锚点）+ entity_timeline（挂 item_id，可批量撤销）
- **用户记忆**：feedback（收藏 / 忽略 / 点击 / 展开）+ 兴趣画像 YAML（初始手写 20-30 行）+ 笔记

| 优先级 | 功能 |
|---|---|
| P0 | 条目全量存储；已读 / 收藏 / 忽略；未读自动过期（默认 48h）；收藏 Inbox |
| P0 | 反馈特征宽表 + ranker_version（第一条反馈前建好） |
| P1 | 白名单实体档案页 + 时间线；**实体变动主动提醒**（收藏 / 深挖过的实体有新条目 → 日报"回顾"段） |
| P1 | Postgres 全文检索（P0 末）→ embedding 语义检索（P1）；"发文字即搜索"（Telegram） |
| P1 | 周报：持续升温 + 我收藏了什么 + 收藏实体新动静 |
| P1 | 收藏时一句备注；收藏夹按实体自动归组 |
| P2 | 兴趣画像自动学习；记忆衰减 / 归档 |

### 3.4 排序层

| 优先级 | 功能 |
|---|---|
| P0 | 规则排序：订阅命中优先 > 平台内分位数热度 × 时间衰减；每因子拆开存 score_breakdown JSON |
| P0 | 反馈即时可感：忽略 → 立即隐藏相似项；标签 / 来源 / 作者的 Beta 平滑偏好当天生效 |
| P1 | 对数域加权求和完整公式（见 02-architecture）；增速按平台快慢分档；跨平台加成（硬合并即生效） |
| P1 | 20% 探索配额；每周排序评估报表（precision@N、忽略在 Top5 占比、来源熵）；evaluate.py 离线回放 |
| P2 | burst 上升话题榜（z-score，≥ 2 源）；GBDT 精排 |
| — | 砍：多视图 / 多维筛选（只留一个流 + 高级折叠）、"更多 / 更少这类"按钮 |

### 3.5 呈现层

**Telegram 日报**（P0，硬约束）：

```
📅 8/18 技术日报 · 6 条

🔥 1. vLLM 0.9 发布：MoE 推理提速 2×  [GH+HN+X]
   官方 blog + benchmark，值得升级        · 命中订阅: 推理框架
   [⭐] [🔍] [🙈]
🧠 2. arXiv: Attention Sink 再研究  [arXiv+X]
   解释了长上下文退化，附代码            · 3 平台同时出现
   [⭐] [🔍] [🙈]
...
📦 另有 12 条订阅命中 → /web
🔁 回顾：你收藏的 llama.cpp 本周有 2 条新动静
⚠️ 源告警：github 连续 2 次失败
💰 今日 LLM 花费 $0.12
```

- Top ≤ 8 必读，每条：标题（跳原文）+ ≤ 40 字一句话 + 来源缩写 + 入选原因 + 3 个 inline 按钮
- 折叠区 ≤ 10 条只有标题
- 尾部：回顾 / 告警 / 花费
- 总长度手机一屏半

**Web**（P0 末 / W2）：HTMX + Jinja2 服务端渲染

- 单流"今日未读"，按分数排，读完标 done，48h 未读自动过期
- 卡片：标题 + 一句话 + 折叠 3 要点 + 来源徽标 + 入选原因 + ⭐/🔍/🙈；**不显示分数、不显示一堆标签**
- Inbox（收藏）；筛选藏"高级"
- P1：搜索页、实体页、事件详情、订阅调参页、debug 分数拆解视图
- 砍：移动端专门适配（Telegram 已覆盖）、Notion / RSS 导出

**Obsidian 投影**（P1）：只读生成，独立目录 `TechRadar/`；实体页 / 日报 / 研究报告；用户笔记单独文件 wikilink 关联；不做回写区块。

## 4. 非功能需求

- 单人维护：任何一个源挂掉不影响其他源；管线幂等可重跑
- 成本：LLM 日预算可配置（默认 $1/天），日报显示当日花费
- 延迟：采集每小时；日报每天 08:00；研究任务 ≤ 10 分钟
- 数据：Postgres 单实例，全部数据本地；embedding 记录 model/version
- 可观测：source_health、agent_tasks、每日埋点（推送数 / 点击数 / 收藏数 / 忽略比例）

## 5. 验收标准（P0）

1. 连续 7 天每天 08:00 收到日报，且愿意看完（主观）
2. 日报 ≤ 8 条主条目 + ≤ 10 条折叠，手机一屏半
3. 每条能看到"为什么推给你"
4. Telegram 内点 ⭐ 后 Web Inbox 可见；点 🙈 后同源相似项当天消失
5. 任一源连续失败 2 次，日报出现告警行
6. 每日 LLM 花费 ≤ 预算，日报可见
7. 3 个源 7 天累计入库 ≥ 500 条，重复率（人工抽样）< 5%

- **W1**：P0 全部（详见 03-roadmap）
